# Definition & purpose

> **Key concept** · A variable stator vane is a compressor stator airfoil whose setting angle can be adjusted about a pivot axis.

A VSV changes the absolute flow direction approaching a downstream rotor, thereby influencing the rotor-relative inlet velocity and incidence. Its purpose is often to improve stage matching across an operating range.

Not every engine uses variable stators. Row count, location, commanded schedule, and mechanism configuration depend on the compressor architecture. Variable inlet guide vanes operate on a related principle but occupy a different blade row position.

<EngineeringNote>
A VSV does not simply “increase airflow.” Its effect must be evaluated as part of the entire compressor operating map.
</EngineeringNote>
